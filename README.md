# Portfólio Rebeca Lago

Abra `index.html` no navegador.

- `index.html` estrutura
- `css/style.css` tokens (cores, fontes, espaçamento) + estilos
- `js/script.js` gera as bordas rasgadas do papel
- `images/` fotos e ícone Aí pra Elas

Fontes via Google Fonts (precisa de internet). Para publicar, envie a pasta inteira para qualquer hospedagem estática (Netlify, Vercel, GitHub Pages, Hostinger).
